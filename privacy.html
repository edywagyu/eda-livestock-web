江田畜産株式会社（以下「当社」といいます）は、お客様の個人情報の取扱いにつきまして、以下のとおりプライバシーポリシーを定めます。当社サービスをご利用いただく前にお読みください。

1. 個人情報の定義

本ポリシーにおける「個人情報」とは、個人情報保護法に定める「個人情報」を指し、生存する個人に関する情報であって、氏名、メールアドレス、電話番号、住所その他の記述等により特定の個人を識別できる情報、および他の情報と容易に照合することができる情報をいいます。

2. 取得する情報

当社は、以下の個人情報を取得します。

  • 氏名・フリガナ
  • メールアドレス
  • 電話番号
  • 郵便番号・住所
  • クレジットカード情報（決済代行会社 Stripe が直接処理し、当社サーバーには保存しません）
  • 注文履歴・配送履歴
  • 診断クイズ・アンケート回答
  • LINE ID（公式アカウント追加時、メッセージ内容を含む）
  • Cookie・アクセスログ・端末情報

3. 利用目的

当社は、取得した個人情報を以下の目的で利用します。

  • 商品の発送・代金決済・配送状況の連絡
  • 定期便会員管理・継続課金
  • 商品・サービスに関するお問い合わせ対応
  • 新商品・キャンペーン・メールマガジンのご案内
  • サービス品質向上のための分析（クイズ回答・アンケート結果）
  • 不正利用の防止
  • その他、上記利用目的に付随する目的

4. 第三者への提供

当社は、以下の場合を除き、お客様の個人情報を第三者に提供しません。

  • お客様の同意がある場合
  • 法令に基づく場合
  • 業務委託先（配送会社、決済代行会社、メール配信会社、クラウドサービス事業者等）に対し、本ポリシーに定める利用目的の範囲内で必要な情報を提供する場合
  • 人の生命、身体または財産の保護のために必要がある場合

具体的な業務委託先

  • 決済処理: Stripe, Inc.（米国）
  • 配送: ヤマト運輸株式会社
  • メール送信・Web ホスティング: Google LLC（Apps Script / Workspace / GitHub Pages）
  • LINE 連携: LINEヤフー株式会社

5. 安全管理措置

当社は、お客様の個人情報の漏洩・滅失・毀損を防止するため、適切な安全管理措置を講じます。具体的には、SSL/TLS による通信暗号化、アクセス権限の最小化、定期的なセキュリティレビュー等を実施します。

6. Cookie・アクセス解析

当サイトでは、サービス改善のため、ページ閲覧情報（閲覧日時、参照元URL等）を自社サーバーに記録しています。これらの情報は個人を特定するものではありません。また、サイトの基本的な機能のために必要最小限の Cookie を使用する場合があります。

7. お客様の権利

お客様はご自身の個人情報について、以下を当社へ請求することができます。

  • 開示
  • 訂正・追加・削除
  • 利用停止・第三者提供の停止

請求は、本ページ末尾のお問い合わせ先までご連絡ください。本人確認のうえ、合理的な期間内に対応いたします。

8. 退会・アカウント削除

定期便のご解約後、当社で定める保管期間（法定保管期間を含む）経過後に個人情報を消去します。即時の削除をご希望の場合はお問い合わせください。

9. プライバシーポリシーの変更

本ポリシーの内容は、法令の改正やサービス変更に応じて適宜変更することがあります。重要な変更があった場合は本サイトに掲示します。
