# 同梱する「次回特典」のA4用紙（片面）

管理画面（staff.html）の発送処理から、その注文のお客様の**次回の特典**を案内する用紙を
**お客様のお名前入り**で印刷するための置き場。

## 仕組み

1. staff.html の発送処理に「お名前」欄（**ご購入者名が最初から入っている**）と印刷ボタンが出る
2. ボタンを押すと `reward-sheet.html?stage=3&name=田崎` が新しいタブで開く
3. ここに置いた**絵柄（Canvaで作ったA4画像）を原寸で敷き、上に「〇〇様」の1行だけ**を刷る
4. そのまま印刷（A4・片面・余白なし・拡大縮小100%）して箱へ

## 置くファイル（Canva から書き出す5枚）

| ファイル | 入れる相手 | 案内する特典 |
|---|---|---|
| `next-2.png` | **1回**ご購入の方 | 送料半額（前回のお届けから40日以内） |
| `next-3.png` | **2回**ご購入の方 | 鶏モモ 200g プレゼント |
| `next-4.png` | **3回**ご購入の方 | 無添加ハンバーグ 2個 プレゼント |
| `next-5.png` | **4回**ご購入の方 | 赤身焼肉 200g プレゼント |
| `next-6.png` | **5回**ご購入の方 | 限定部位を買える権利（イチボ・シンシン等） |

ファイル名の数字は「**次にもらえる回**」。1回買った人には次が2回目なので `next-2.png`。

- `.jpg` でも動く（png → jpg の順に探す）。
- 🔴 **「〇〇様」の行だけは絵柄に入れない**。そこはシステムが刷る。上から数十mmの位置に
  高さ10mm程度の空白を空けておくこと（位置は印刷ページの数字で合わせられる）。
- 絵柄を置いていない回は、**下書きの見た目**（`SHEET_TEXT` の文言を組んだ紙面）のまま印刷できる。

## 文言（下書き用）を直すところ

`reward-sheet.html` の **`SHEET_TEXT`**。絵柄を置いた回では使われない（絵柄の中の文字が出る）。

🔴 特典の中身の正は `mypage.html` の `REWARD_STAGES`。変えたときは
`staff.html` の `REWARD_LADDER` と3点セットで直すこと。

## QRコード

紙に載せるQRの飛び先は `https://www.eda-livestock.com/mypage.html?src=insert`
（スキャン → 「LINEで会員登録／ログイン」→ 登録と公式LINE連携が同時に完了する）。
`?src=insert` は紙からの流入を数えるための印。**QRはCanvaに画像として貼る**。

## 差し替え方

同じファイル名で上書きしてPRを出す。画面側のコード修正は不要。
