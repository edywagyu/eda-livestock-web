# 同梱する「次回特典」のA4用紙（片面）

管理画面（staff.html）の発送処理から、その注文のお客様の**次回の特典**を案内する用紙を
**お客様のお名前入り**で印刷するための置き場。

## 仕組み

1. staff.html の発送処理に「お名前」欄（**ご購入者名が最初から入っている**）と印刷ボタンが出る
2. ボタンを押すと `reward-sheet.html?stage=3&name=田崎` が新しいタブで開く
3. そのまま印刷（A4・片面・余白なし・拡大縮小100%・背景のグラフィックあり）して箱へ

**デザインは2回目〜6回目とも全部同じ。変わるのは文言だけ**（2026-08-31 田崎さん決定）。

## 文言を直すところ

`reward-sheet.html` の **`SHEET_TEXT`** ただ1つ。回ごとに `main`（大きく出す特典名）と
`sub`（1行の説明）を持つ。共通の挨拶文・注意書きは同ファイルの紙面HTMLに直書き。

🔴 特典の中身の正は `mypage.html` の `REWARD_STAGES`。変えたときは
`staff.html` の `REWARD_LADDER` と3点セットで直すこと。

## 置くファイル（Canva から）

| ファイル | 中身 | 無いとどうなる |
|---|---|---|
| `base.png` | **全回共通の絵柄**（枠・飾り・ロゴなど）。A4 210×297mm 縦・フチなし | 下書きの見た目のまま印刷される（それでも成立する） |
| `line-qr.png` | QRコード（正方形） | 点線の「QRはここに入ります（未確定）」枠が出る |

- `.jpg` でも動く（png → jpg の順に探す）。
- 🔴 **`base.png` に文字は入れない**。文字はこのページが上に刷るので、絵柄側に入れると重なる。
- `base.png` を置くと、下書き用の飾り（背景色・ロゴ・罫線・白い枠）は自動で引っ込む。
- 文字全体の上下位置は印刷ページのツールバーで調整できる（そのパソコンに記憶される）。

## 差し替え方

同じファイル名で上書きしてPRを出す。画面側のコード修正は不要。
