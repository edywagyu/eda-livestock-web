# 同梱する「次回特典」のA4用紙（PDF）

管理画面（staff.html）の発送処理で、その注文のお客様の**次回の特典**を案内する用紙を開くための置き場。

## ファイル名（固定）

| ファイル | 案内する回 | 特典 |
|---|---|---|
| `next-2.pdf` | 2回目 | 送料半額（前回のお届けから40日以内・自動適用） |
| `next-3.pdf` | 3回目 | 鶏モモ 200g プレゼント |
| `next-4.pdf` | 4回目 | 無添加ハンバーグ 2個 プレゼント |
| `next-5.pdf` | 5回目 | 牛焼肉 200g プレゼント |
| `next-6.pdf` | 6回目 | 限定部位を買える権利（イチボ・シンシン等） |

- **1回目のご注文をした人には `next-2.pdf`** が出る（次にもらえるのが2回目特典のため）。
- 7回目以降は特典が未設定なので、用紙も出ない（画面には「まだ決まっていません」と出る）。
- ファイルが無い回は、画面のボタンが「未登録です」に変わる（404を踏まない）。

## 差し替え方

同じファイル名で上書きしてPRを出す。画面側のコード修正は不要。
ドライブ等に置きたい場合は staff.html の `REWARD_SHEET_PDFS` にそのURLを書けば、そのまま開く。

## 特典の中身を変えたとき

特典の正は `mypage.html` の `REWARD_STAGES`。**staff.html の `REWARD_LADDER` と対で直す**こと
（片方だけ直すと、お客様に見える案内と梱包の指示がズレる）。
