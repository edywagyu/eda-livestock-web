# 同梱する「次回特典」のA4用紙

管理画面（staff.html）の発送処理で、その注文のお客様の**次回の特典**を案内する用紙を、
**お客様のお名前入り**で印刷するための置き場。

## 仕組み

1. staff.html の発送処理に「お名前」欄（**ご購入者名が最初から入っている**）と印刷ボタンが出る
2. ボタンを押すと `reward-sheet.html?stage=3&name=田崎` が新しいタブで開く
3. そのページが **ここに置いた絵柄（A4画像）を原寸で敷き、上に1行だけ重ねて**表示する
   → `〇〇様　ご購入いただきありがとうございます`
4. そのまま印刷（A4・余白なし・拡大縮小100%）して箱へ

## ファイル名（固定）

| ファイル | 案内する回 | 特典 |
|---|---|---|
| `next-2.png` | 2回目 | 送料半額（前回のお届けから40日以内・自動適用） |
| `next-3.png` | 3回目 | 鶏モモ 200g プレゼント |
| `next-4.png` | 4回目 | 無添加ハンバーグ 2個 プレゼント |
| `next-5.png` | 5回目 | 牛焼肉 200g プレゼント |
| `next-6.png` | 6回目 | 限定部位を買える権利（イチボ・シンシン等） |

- `.jpg` でも動く（`reward-sheet.html` が png → jpg の順に探す）。
- **1回目のご注文をした人には `next-2` の絵柄**が出る（次にもらえるのが2回目特典のため）。
- 7回目以降は特典が未設定なので用紙も出ない（画面には「まだ決まっていません」と出る）。
- 絵柄が無い回は、画面のボタンが「絵柄が未登録です」に変わる（白紙を刷らない）。

## Canva からの書き出し方

- サイズ：**A4（210 × 297mm）縦**、フチなし（塗り足しは不要）
- 形式：**PNG**（写真が多いなら JPG でも可）／おおむね 300dpi 相当
- 🔴 **一番上に「お名前の1行ぶん」を空けておく**こと。ここに文字を重ねるため、
  絵柄側に文字を置くと重なって読めなくなる。
- 名前の**位置（上から何mm）と文字の大きさ**は `reward-sheet.html` のツールバーで
  合わせられる（合わせた値はそのパソコンに記憶されるので、最初の1回だけでよい）。

## 差し替え方

同じファイル名で上書きしてPRを出す。画面側のコード修正は不要。

## 特典の中身を変えたとき

特典の正は `mypage.html` の `REWARD_STAGES`。**staff.html の `REWARD_LADDER` と対で直す**こと
（片方だけ直すと、お客様に見える案内と梱包の指示がズレる）。
