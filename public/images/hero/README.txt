ヒーロー写真スロット — Tom 用

各ページのヒーロー（最上部の大きな見出しエリア）に実写を入れたい場合、
このフォルダに写真を置いて、HTML の img src を差し替えてください。

──────────────────────────────────────────────
1. index.html (トップページ)
──────────────────────────────────────────────
場所: index.html 内の <img class="hero-photo">
推奨ファイル名: hero-pasture.jpg
推奨サイズ: 2560×1440 以上、横長 JPEG
推奨イメージ: 牧場の朝・牛・畜舎・宮崎の山並みなど
書き換え例:
  src=""  →  src="public/images/hero/hero-pasture.jpg"

──────────────────────────────────────────────
2. shop.html (オンラインショップ)
──────────────────────────────────────────────
場所: shop.html 内の <img class="shop-hero-img">
推奨ファイル名: shop-cuts.jpg
推奨イメージ: 部位カット・盛り付け・厨房・お肉そのものが映る写真

──────────────────────────────────────────────
3. subscription.html (月の定期便)
──────────────────────────────────────────────
場所: subscription.html 内の <img class="sub-hero-photo">
推奨ファイル名: subscription-table.jpg
推奨イメージ: 家族の食卓・冷凍庫が満たされている様子・盛り合わせ

──────────────────────────────────────────────
仕組み
──────────────────────────────────────────────
src が空（src=""）のときは img が CSS で hidden になり、
グラデ背景のみが表示されます。
src を入れた瞬間に、写真が表示されます。

写真は CSS の mix-blend-mode で
forest×gold のブランドカラーと自然に馴染むよう調整済み。

そのままドロップで OK です。
