# エダチク米の送料（常温便）— GAS 側の修正コード

**まだ本番GASには入れていません。** `clasp push` は田崎さんの承認後。

## 中身

- `2026-10-26-rice-shipping.Code.gs.patch` — **これを当てる**。`gas/Code.gs` に対する差分（unified diff）
- `2026-10-26-rice-shipping.Code.gs.new` — 差分を当てた結果の**見本**。中身を読んで確認するためだけのもの

🔴 **`.new` を本番の `Code.gs` に丸ごと上書きしないこと。**
本番GASには、このリポジトリに反映されていない他の作業の変更が入っていることがあります。
丸ごと差し替えると、それを**全部消します**（過去に同じ形の事故があります）。
入れるのは**差分だけ**です。

## 変える規則

- お米は常温便。送料は全国一律 ¥1,100（税込／税抜1,000円・送料は10%）
- 「¥11,000以上で送料無料」の**対象外**。20kg(¥14,256)を1点だけ買っても ¥1,100 かかる
- お肉（冷凍便）と同時購入なら**送料2件分**（冷凍便の既存ロジック ＋ お米の常温便 ¥1,100）
- お米の金額は冷凍便側の送料無料判定の小計に**含めない**
- freeShip 商品（はじめてセット等）・リピート送料半額・北海道沖縄の加算は、
  いずれもお米には効かせない

同じ規則が `checkout.html` の `renderSummary` にも入っています（表示と請求の二重実装）。
**片方だけ直すと画面の金額と請求がズレます。**

## 入れ方（田崎さんの承認が出てから）

1. `clasp pull` で**本番の現物**を取る
2. **その現物に `.patch` を当てる。**`.new` での丸ごと差し替えはしない

   ```
   git apply --3way gas/patches/2026-10-26-rice-shipping.Code.gs.patch
   ```

   当たらなかったら、本番側が動いているということです。**force で通さず、
   当たらなかった場所を目で見てから手で入れてください。**
3. 当てたあとの `Code.gs` の差分を読む。**自分が足した行以外に削除行（-）が無いこと**を確認する
4. `clasp push`
5. もう一度 `clasp pull` して照合する
6. **デプロイの版を上げる**（`clasp push` は @HEAD しか更新しない）

## 確認したいこと

- お米だけを複数のお届け先（ギフト）に分けた場合、常温便は実際には口数ぶん
  出ることになりますが、このコードは1注文あたり ¥1,100 を1回だけ取ります。
  口数ぶん頂くなら直す必要があります。
