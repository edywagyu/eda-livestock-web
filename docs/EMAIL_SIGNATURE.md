## 設定手順 (Gmail)

1. https://mail.google.com → 右上の歯車 → 「すべての設定を表示」
2. 「全般」タブ → 「署名」セクション
3. 「新規作成」→ 名前: 「Main (with booking)」
4. 上記HTMLリッチ版を「リッチテキスト」モードで貼り付け
5. 「署名のデフォルト」で新規メール・返信両方に設定
6. 一番下「変更を保存」
