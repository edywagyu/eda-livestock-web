1 システム全体像

本システムは、Shopifyなどの外部ECプラットフォームを使わず、自社サイト + Stripe + LINE + Googleスプレッドシートだけで EC運営を完結させる仕組みです。

お客様が触れるもの

  • ECサイト（GitHub Pages）
  • 商品ページ・カート
  • Stripe決済画面
  • 注文完了ページ
  • マイページ
  • LINE公式アカウント

裏側（自動）

  • Google Apps Script
  • Stripe Webhook
  • LINE Messaging API
  • 顧客自動マッチング
  • 在庫自動更新
  • 配送ラベル自動生成

EC担当者が使うもの

  • Googleスプレッドシート
  • 管理ダッシュボード
  • B2 CSVダウンロード
  • ヤマトB2クラウド
  • Stripe管理画面
ポイント EC担当者が日常的に触るのは Googleスプレッドシート と 管理ダッシュボード の2つだけです。注文受付・顧客登録・LINE通知は全て自動で行われます。

各ステップの詳細

ステップお客様の操作裏側で起こること
1. 商品選択 shop.html で商品を選び「カートに追加」ボタンを押す ブラウザの localStorage にカート情報を保存（サーバー通信なし）
2. カート確認 カートドロワーで数量変更・削除。送料無料ラインを表示 なし（全てブラウザ内）
3. レジに進む 「レジに進む」ボタン → Stripe決済画面に自動遷移 GAS API にカート内容を送信 → Stripe Checkout Session を作成 → Stripe の決済URLを返す
4. 決済 Stripe画面で名前・住所・カード情報を入力して決済 Stripe が決済処理。完了後 Webhook を GAS に送信
5. 注文完了 order-complete.html に戻り、注文番号を確認 スプシに注文書き込み、配送ラベル自動生成、LINE通知（連携済みの場合）

6 配送ラベル（ヤマトB2）

発送作業の手順

  1. ダッシュボードを開く
    GAS Web App URL にアクセス → 「📦 配送ラベル CSV」ボタンをクリック
  2. プレビューで内容確認
    「👁 プレビュー」ボタンで未発送件数と内容を確認。住所や電話番号に間違いがないかチェック
  3. CSVをダウンロード
    「📥 Shift_JIS版」をクリック（B2クラウドはShift_JISが必要）。Excelで開く場合は「UTF-8版」を選択
  4. ヤマトB2クラウドにアップロード
    B2クラウドにログイン → 「送り状データ取り込み」→ ダウンロードしたCSVをアップロード
  5. 伝票番号をスプシに入力
    B2クラウドで発行された伝票番号を、EC受注シートのT列に入力。
    → 自動で配送STSが「発送済」に変わり、LINEで追跡URL付きの発送通知が送信されます

B2 CSV の仕様

項目値
フォーマットヤマトB2クラウド標準（29列）
文字コードShift_JIS（B2クラウド用）/ UTF-8（Excel用）
送り状種類0（発払い）
クール区分冷凍=2 / 冷蔵=1 / 通常=0
デフォルトサイズ080サイズ
荷扱い下積厳禁
品名「江田和牛」（鶏商品がある場合は「江田和牛・平飼い鶏」）
依頼主江田畜産株式会社 / 宮崎県宮崎市高原町 / 0984-42-3129
注意: CSV出力済みフラグ CSVをダウンロードすると、対象の注文は自動で「B2出力済=TRUE」「配送STS=発送準備中」に変わります。同じ注文が二重にCSV出力されることはありません。

9 初期セットアップ手順

  1. Googleスプレッドシートを作成
    Google Drive で新規スプレッドシートを作成。名前は「江田畜産 EC管理」など。
  2. GASエディタを開く
    スプレッドシートのメニュー → 拡張機能 → Apps Script を開く。
  3. コードファイルをコピー
    eda-ec-backend/ フォルダ内の全 .gs ファイルをGASエディタに新規ファイルとして作成・貼り付け。appsscript.json はプロジェクト設定で反映。
  4. setupAllSheets() を実行
    GASエディタで setupAllSheets 関数を選択 → ▶ 実行。6つのタブが自動作成されます。初回実行時にGoogleへの権限許可が求められます。
  5. APIキーを設定
    GASエディタで setupApiKeys 関数のプレースホルダーを実際のキーに置き換えて実行。
    または、プロジェクト設定 → スクリプトプロパティ で手動入力：
    キー名値取得場所
    STRIPE_SECRET_KEYsk_live_...Stripe Dashboard → API キー
    STRIPE_PUBLISHABLE_KEYpk_live_...Stripe Dashboard → API キー
    LINE_CHANNEL_ACCESS_TOKENトークン文字列LINE Developers → Messaging API
    LINE_CHANNEL_SECRETシークレット文字列LINE Developers → チャネル基本設定
    SITE_URLhttps://edywagyu.github.io/eda-livestock-web（固定値）
  6. ウェブアプリとしてデプロイ
    GASエディタ → デプロイ → 新しいデプロイ → 種類「ウェブアプリ」→ アクセス「全員」→ デプロイ。
    表示される URL をメモ（これがダッシュボード兼 API エンドポイント）。
  7. サイトのAPI URLを設定
    以下の3ファイルの YOUR_DEPLOYMENT_ID を、デプロイで取得した実際のIDに置き換え：
    • _partials/scripts.html （カート決済）
    • mypage.html （マイページ）
    • order-complete.html （注文完了ページ）
  8. Stripe Webhook を登録
    Stripe Dashboard → 開発者 → Webhook → エンドポイント追加：
    URL: https://script.google.com/macros/s/{デプロイID}/exec?action=stripe_webhook
    イベント: checkout.session.completed
  9. LINE Webhook を登録
    LINE Developers → Messaging API → Webhook URL：
    https://script.google.com/macros/s/{デプロイID}/exec?action=line_webhook
    Webhook利用: ON
  10. 定期実行トリガーを設定
    GASエディタで setupTriggers 関数を実行。顧客マッチング（6時間）・在庫更新（毎朝6時）・LINE_UID補完（毎朝7時）が自動設定されます。

11 トラブルシューティング

症状原因対処法
「レジに進む」を押しても何も起きない GAS API URL が未設定、またはデプロイが古い scripts.html の GAS_API_URL を確認。GASで「新しいデプロイ」を作り直す
注文したのにスプシに記録されない Stripe Webhook が正しく設定されていない Stripe Dashboard → Webhooks → イベント配信ログを確認。URLが正しいか、?action=stripe_webhook がついているか
LINE通知が飛ばない 顧客のLINE_UIDが空（未連携） LINE友だち追加 → EC購入の順序だと自動紐付け。EC顧客シートで LINE_UID が入っているか確認
伝票番号を入れたのに発送通知が出ない on-editトリガーが未設定、またはLINE_UIDが空 GASエディタ → トリガー → onOrderSheetEdit がスプシ編集トリガーに設定されているか確認
B2 CSVが文字化けする UTF-8版をB2クラウドにアップした 「Shift_JIS版」を使う。ExcelはUTF-8版を使う
マイページでログインできない メールアドレスまたは電話番号がスプシと一致しない EC顧客シートのE列（メール）・F列（電話）を確認。Stripe決済時に入力したものと同じか
同じ注文が2回記録された 通常は重複チェック機能で防止されるが、Webhook再送時に稀に発生 EC受注シートのB列（StripeセッションID）で重複行を探して、後から入った方を削除
GASの実行ログにエラーが出ている 様々（API制限、権限エラーなど） GASエディタ → 実行 → 実行ログを確認。エラーメッセージをもとに対応
絶対にやってはいけないこと • EC受注シートのA列（受注ID）・B列（StripeセッションID）を手動変更しない
• 配送ラベルシートのデータを手動編集しない（CSVが壊れます）
• スクリプトプロパティのAPIキーを他人に共有しない

APIエンドポイント一覧

全て GAS Web App URL（https://script.google.com/macros/s/{ID}/exec）に対するリクエストです。

メソッドaction パラメータ用途呼び出し元
POST create_checkout Stripe Checkout Session を作成して決済URLを返す shop.html のカート
POST stripe_webhook Stripe決済完了通知を受け取り、注文をスプシに書き込む Stripe（自動）
POST line_webhook LINE のイベント（友だち追加・メッセージ等）を処理 LINE（自動）
GET customer_lookup メール or 電話で顧客情報・注文履歴を取得 mypage.html
GET order_status Stripe セッションIDで注文情報を取得 order-complete.html
GET dashboard 管理ダッシュボードHTML（デフォルト） EC担当者ブラウザ
GET b2_csv B2 CSVダウンロードページHTML ダッシュボード
GET b2_csv_data B2 CSV データ生成（内部呼び出し） CSVダウンロードJS
