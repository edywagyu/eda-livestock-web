# お歳暮投稿の日付統計リサーチ（食品・畜産物カテゴリ）

調査日: 2026-10-14

## 0. 調査方法と制約（重要）

本調査は Instagram の投稿タイムスタンプを直接収集することを目指したが、**実行環境のネットワークポリシーが `www.instagram.com` および `prtimes.jp` への接続を拒否した**（CONNECT に 403）。そのため投稿単位のスクレイピングはできていない。

代わりに、検索エンジン経由で取得できる公開一次情報（各社ニュースリリース、百貨店の承り期間告知、SNSキャンペーン告知）から**「日付が確定している告知イベント」を収集し、その分布を集計**した。企業の Instagram 投稿はほぼ例外なくこれらの日付（販売開始・承り開始・早割締切・配送締切）に同期して打たれるため、投稿カレンダーの代理指標として使える。

投稿件数ベースの実データが必要な場合は、環境設定の Network access で `instagram.com` を許可ドメインに追加すれば再取得できる（設定手順: https://code.claude.com/docs/en/cloud-environments#network-access ）。

**ピーク構造は二山。**
- 第1の山 = **10月1日〜10月20日**（全体の約 39%、11/28件）。メーカー発表と承り開始が集中する「告知の山」。
- 第2の山 = **11月上旬〜11月中旬**（7/28件）。早割締切とSNSキャンペーンが重なる「刈り取りの山」。
- 12月は締切日の列挙で、投稿内容は「お届け期限」訴求に変質する。

## 3. 需要側のタイミング（照合データ）

- Googleトレンド上、「お歳暮」の検索は**11月後半から12月初旬にかけて急上昇**する。企業の告知ピーク（10月上旬）より約1.5か月遅い。
- 贈答マナーの一般解は **12月13日〜12月20日着**。関東は12月初旬から、関西は12月10〜13日以降が目安。
- 近年は前倒し傾向があり、**11月下旬着**の手配が増えている。
- 生鮮・冷蔵の畜産品は **12月25日頃までの到着**を目安にする案内が多い（年末年始の食卓需要に接続するため）。

→ **供給側の告知ピーク（10月上旬）と、消費者の検索ピーク（11月後半〜12月初旬）に約6週間のズレがある。** 10月の投稿はリーチが伸びにくく、11月後半〜12月初旬に再訴求しない企業は検索需要の山を取りこぼす構造になっている。

## 4. 畜産物カテゴリ特有の論点

1. **早割の締切日が投稿の実質的な締切**。三越伊勢丹 11/7、近鉄 11/30、そごう西武 12/10 と3〜5週間ばらける。販路別に投稿日を分ける必要がある。
2. **産地直送品の承り締切が一般商材より1週間早い**（東急: 12/17 vs 全体 12/25）。産直の和牛・豚肉を扱う場合、12月前半に「産直は締切が早い」という投稿が必須。
3. **SNSプレゼント企画は11月中旬に置かれている**（ミヤチクの例: 11/13告知→11/15締切）。カタログ販売開始（10/15）から約1か月後で、早割締切と重ねる設計。
4. **12月28日以降は「お歳暮」から「年末年始のごちそう・おせち・SALE」へ訴求が切り替わる**（ミヤチクの年末年始SALEが12/28開始）。お歳暮ハッシュタグの寿命は実質12月25日まで。

| 時期 | 投稿テーマ | 根拠 |
|---|---|---|
| 10/1〜10/10 | ラインナップ公開・受付開始告知 | メーカー告知の最大密度帯 |
| 10/15〜10/31 | 商品詳細（部位・産地・加工）、早割訴求の開始 | 百貨店承り開始に同期 |

| 11/10〜11/20 | **プレゼント/フォロー企画をここに置く** | 業界慣行の実施帯、検索需要の立ち上がり直前 |
| 11/20〜12/5 | 本命の指名検索を取る投稿（用途別・価格帯別） | Googleトレンドのピーク帯 |
| 12/5〜12/15 | 「12/20着」逆算の配送締切訴求、産直は締切前倒しを明記 | 一般的な到着目安・産直締切 |
| 12/16〜12/25 | 最終受付・生鮮の年末着訴求 | 承り終了ラッシュ |
| 12/26〜 | 年末年始ごちそう・SALEへ切替 | 12/28以降の業界慣行 |
