## 手順

### 1. 本番DB products タブ（ここが請求の正本）

スプレッド `1k98VW296Quw7F9-HqFNwtGKxfySGjdAA-FE1vobX3Nk` の `products` タブ（gid 144544549）。

米8行の **G列 `price`** を上の表の「12/1から」の数字に書き換える。

- **触るのは price の8セルだけ。** 行の削除・シート削除・英語ヘッダーの変更は禁止
- `stripePriceId` は8点とも**空のまま**にする。ここに固定額のIDが入っていると、
  表示を変えても請求が旧価格のままになる（スキルの⑤価格変更の罠）
- `listPrice` 列はこのタブに**無い**（22列）。増やさなくてよい

### 2. リポジトリ（表示側）

`public/data/products-master.js` の米8点:

- `price` を「12/1から」の数字に変更
- **`listPrice` を削除する。** 値上げ後は「12月1日から ¥◯」という将来価格が
  存在しないため、併記する相手がいない。
  🔴 `listPrice` を残したまま price だけ上げると `listPrice > price` が成立せず
     併記は消えるが、データとしては嘘が残るので消すこと

`public/data/pdp-content.js` の米8点:

- 🔴 **`combo[].price` を12月価格に（16箇所）。ここを直さないと「よく一緒に買われています」
  から12月以降も11月価格でカートに入り続けます。**
  `product.html` の `unit: x.pr || x.p.price || 0` で pdp-content の値がマスターより優先され、
  その `unit` がそのままカートに入るためです。
  本番シートが ¥8,640 でも ¥3,564 で売れます（1点あたり5,076円の取りこぼし）。
  **公開当日は値が一致していて気づけません。**
  対象は米8点 × 併買2件（自分＋同容量のもう一方の形態）＝16箇所:
  `3564→8640` / `7128→17280` / `10692→25920` / `14256→34560`
- 直したら **各HTMLの `pdp-content.js?v=` も更新**（product / line-members 3枚 / oseibo / vip-preorder の6ページ）

  2026-10-26 に、シート・マスター・カードだけ直した状態を再現して実測しました。
  主価格は ¥8,640 になるのに、併買カードは ¥3,564 のまま・ボタンは「¥12,128」でした。
  上の手順を足すと、併買も ¥8,640・ボタン「¥22,280」になることまで確認しています。

`shop.html` / `products.html` の米カード8枚:

- 🔴 `data-variants` の `"p"` を新価格に（**ここを直さないとカートに旧価格が入る**）
- `<span class="product-price">` の表示金額
- `<div class="rice-card-notice">…</div>` のブロックを**8枚とも削除**

`product.html`:

- `renderPrice` の米分岐（`.rice-price-notice` を出す部分）と、
  `.rice-price-notice` / `.rice-pn-*` のCSSを削除

キャッシュ:

- `sw.js` の `CACHE_VERSION` を +1
- 各HTMLの `products-master.js?v=` を更新

### 3. 反映

PRを作る → 田崎さんの承認 → マージ。**シート(1)とサイト(2)は同じ日に揃える。**
片方だけだと、表示と請求がズレます。

## 確認（反映後）

1. 商品ページで8点の価格が新価格になっている
2. カートに入れて、レジの「商品小計」が新価格で出る
3. **送料はお米だけ ¥1,100（税込）のまま**。20kg単品 ¥34,560 でも
   「¥11,000以上で送料無料」の対象外であること（値上げ後も変わらない）
4. 「11/30まで」「12月1日から」の文言がサイトから消えていること
5. 🔴 **商品ページの「よく一緒に買われています」の4枚が全部12月価格**で、
   ボタンの合計も12月価格で計算されていること（主価格だけ見て終わらない）
6. 実際にそのボタンでカートに入れ、**レジの商品小計が12月価格**になっていること

## 注意

- **「値上げしました」「旧価格」などの比較表示は出さないこと。** 販売実績が
  8週間ルール（過去8週間の過半かつ通算2週間以上）を満たさないため、
  過去価格との二重価格表示は不当表示になる
- 11月30日は**月曜**、12月1日は**火曜**
