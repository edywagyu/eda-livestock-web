⚙️ ダッシュボード設定

※ Google Apps Script で公開した Web App の URL を貼り付けてください。
ダッシュボード / shop / subscription / order-complete すべてここから取得した URL を共有します。

📚 GAS エンドポイント仕様

必要なアクション
GET ?action=public_products ・・・ 公開商品一覧
GET ?action=dashboard&range=30d ・・・ ダッシュボード集計
GET ?action=orders&from=YYYY-MM-DD ・・・ 注文一覧
GET ?action=subscriptions ・・・ 定期便メンバー
GET ?action=customers ・・・ 顧客CRM
GET ?action=survey_responses ・・・ アンケート結果
GET ?action=quiz_responses ・・・ 診断回答
GET ?action=line_friends ・・・ LINE 友だち
GET ?action=shipments ・・・ 配送状況
GET ?action=order_status&session_id=XXX ・・・ Stripe 後の照会

POST ?action=submit_order ・・・ 注文書き込み
POST ?action=submit_quiz ・・・ クイズ回答
POST ?action=submit_survey ・・・ アンケート
POST ?action=log_subscription_application ・・・ 定期申込ログ
POST ?action=stripe_webhook ・・・ 決済確定
POST ?action=line_webhook ・・・ LINE Bot

Sheets タブ構成
📦 orders — 注文ヘッダ (order_number, customer, total, mode, payment, ts)
📦 order_items — 注文明細 (order_number, sku, qty, unit_price)
⭐ subscriptions — 定期便契約
👥 customers — 顧客マスタ
📋 survey_responses — アンケート (organic / source / meats)
🧠 quiz_responses — 診断クイズ
💬 line_events — 友だち追加・ブロック・メッセージ
🚚 shipments — 配送追跡
📊 daily_kpi — 日次集計 (cron で毎日生成)
